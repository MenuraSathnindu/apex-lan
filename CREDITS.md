# Credits

apex-lan's own code is MIT ([`LICENSE`](LICENSE)). This file lists everything else: the data
we ship, the optional art we download, and the libraries we build on. If you add a
third-party file, add it here (and to [`client/public/CREDITS.md`](client/public/CREDITS.md),
which ships with the game) in the same change.

## Track data (shipped in `client/public/tracks/`)

The 45 circuit layouts are generated by `tools/build-tracks.ts` from two open datasets. Our
processing (resampling, smoothing, alignment, width clamping, start lines, zones, grid and pit
lane) is a modification of that data, so the generated files keep the datasets' licences.
Licence texts ship next to the data; [`ATTRIBUTION.md`](client/public/tracks/ATTRIBUTION.md)
explains it, and every `<id>.json` names its source in its `source` block.

| Dataset | Author | Licence | Link | Used for |
|---|---|---|---|---|
| racetrack-database | Chair of Automotive Technology, Technical University of Munich (TUMFTM) | LGPL-3.0 ([text](client/public/tracks/LICENSE-TUMFTM-racetrack-database.txt)) | <https://github.com/TUMFTM/racetrack-database> | Centrelines and track widths, where available |
| Circuits GeoJSON | Tomislav Bacinger | MIT ([text](client/public/tracks/LICENSE-bacinger-circuits.txt)) | <https://github.com/bacinger/f1-circuits> | Geographic reference, start/finish line, published lengths, and the centreline of circuits not in the TUMFTM set |
| Map data (the TUMFTM centrelines are originally from it) | © OpenStreetMap contributors | ODbL-1.0 | <https://www.openstreetmap.org/copyright> | Origin of the TUMFTM centrelines |

Track names are places (city/area and country), used only to say where a layout is.
