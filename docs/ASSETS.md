# Art assets

Every third-party asset, dataset and library, with author, licence and link:
[`CREDITS.md`](../CREDITS.md).

The game runs without any of these files: each one has a procedural fallback (sky, flat
textures, built-in car), and the browser console says which file is missing. With them, it
looks realistic.

**Easiest:** run `npm run assets` from the repo root. It downloads everything below into
the right folders (about 30 MB) and skips files you already have.

The files are git-ignored, so each machine that hosts the game needs them once. Players
who join don't need anything.

Save each file under `client/public/` at exactly the path shown. Keep the file names;
they're referenced in `shared/src/tuning.ts` → `ASSETS`.

### Car: open-wheel model (optional, bring your own)
Nothing to download. The game builds an open-wheel car in code. To use a real model, save a
GLB as `client/public/models/openwheel.glb`. **Requirements** (axes, wheel and wing node
names, livery material names): [`OPENWHEEL_MODEL.md`](OPENWHEEL_MODEL.md). It must be original
or CC0/CC-BY and must not show a real team's car, logos or livery.

### Sounds (optional, no download needed)
The game **generates placeholder sounds in code** (engine, tyre screech, barrier scrape,
impacts), so there is nothing to download. To use real recordings instead, drop any of these
into `client/public/sounds/` (git-ignored; any format the browser decodes. `.ogg` works in
Chrome, Edge and Firefox; change the names in `AUDIO.files` for `.mp3`/`.wav`):

| File | What it should be |
|---|---|
| `sounds/engine.ogg` | A seamless engine loop **on load at a steady rpm**. Set `AUDIO.files.engineFileRpm` to that rpm (default 3000); pitch is scaled from it. |
| `sounds/skid.ogg` | A seamless tyre-screech loop. |
| `sounds/scrape.ogg` | A seamless metal-scrape loop. |
| `sounds/impact.ogg` | One short collision thud/crunch. |

Only use CC0 / CC-BY sounds (e.g. freesound.org filtered by licence) and add them to
`client/public/CREDITS.md`. The console reports how many sound files were found.

## Swapping in different assets
- **Another HDRI:** drop any equirectangular `.hdr` in `hdri/` and change `ASSETS.hdri`. The
  sun direction is detected from the image's brightest spot, so shadows match automatically.
  Override it with `ENVIRONMENT.sunDirection` if needed. "Pure sky" HDRIs work best,
  because the track supplies its own ground.
- **Other textures:** any Poly Haven / ambientCG set with diffuse + GL normal + roughness.
  Update `ASSETS.asphalt` / `ASSETS.grass`, including `tileSize` (metres per repeat).
- **Another car:** any GLB with four separate wheel nodes. Set `CAR_MODEL.wheelNodes` to their
  names (FL, FR, RL, RR). Set `CAR_MODEL.yawOffset` so the car faces +Z (0 if it already does,
  π if it faces −Z). Set `CAR_MODEL.materials` to substrings of its paint/glass/light material
  names. The model is auto-scaled to the physics wheelbase. If the console says wheel
  nodes are missing, it lists every node name in the file.
  For a different car *size*, also change `CAR.wheels` / `CAR.chassis` and re-run `npm run handling`.
