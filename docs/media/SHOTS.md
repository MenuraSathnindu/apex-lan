# README screenshots

Capture these at 1920×1080 on the High preset with `npm run assets` done, then uncomment the
image block at the top of `README.md`. Keep each PNG under ~1 MB and the GIF under ~8 MB
(e.g. 800 px wide, 15 fps). Use fictional player names and no photos of real people.

| File | Shot |
|---|---|
| `race-start.gif` | ~10 s from behind the grid: five red lights come on, go out, the pack launches into turn 1 (Monza or Spa, 6–8 cars with `npm run bots -- 7`) |
| `pack-racing.png` | Chase camera in the middle of a close pack, battery/boost HUD visible |
| `timing-tower.png` | Mid-race: timing tower on the left with gaps, a purple/green sector and the lap delta popup |
| `pit-stop.png` | Car stopped in the pit box with the tyre picker open |
| `podium.png` | Podium scene with the top-3 cards and photos |
| `lobby.png` | Lobby with several players, profile photos and liveries |
| `track-select.png` | Track select screen showing the circuit previews |
| `standings.png` | Championship drivers' and teams' standings after a round |
